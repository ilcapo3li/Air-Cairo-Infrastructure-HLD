# 11. Points for Client Confirmation
1. Two sites: is a minimum-capacity DR site that scales up on failover acceptable?
2. 3TB bandwidth: per month? Per environment or production only?
3. Target availability %, RPO and RTO expected by the client?
4. Data residency: is hosting outside Egypt accepted?
5. Is a dedicated network firewall appliance required, or are Network Security Groups accepted?
6. Expected users: public visitors, agents, admins, and peak concurrent users?
7. Expected data volume and AWBs per month?
8. Hosting SLA duration: 12 months?
9. Confirm the client will own the Azure subscription and Cloudflare account and pay them directly.
10. Allowed maintenance window per month?
11. Is there an existing SOC/SIEM to integrate with?
12. Bidding terms: submission deadline, evaluation criteria, commercial terms, and whether partial bids or consortiums are permitted.
